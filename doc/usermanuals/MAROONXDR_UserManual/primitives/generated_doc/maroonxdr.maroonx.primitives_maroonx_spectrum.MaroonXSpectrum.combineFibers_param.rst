Parameter defaults and options
------------------------------
::

   suffix               ''                   Filename suffix
   combine_fibers       None                 List of fibers to combine.
   symmetric_linefits   False                Symmetric line fits
   kappa_sigma          5.0                  Sigma clipping threshold for outlier rejection
   max_clips            5000                 Maximum pixels to clip per order before increasing kappa_sigma
   report               True                 Generate PDF diagnostic report
