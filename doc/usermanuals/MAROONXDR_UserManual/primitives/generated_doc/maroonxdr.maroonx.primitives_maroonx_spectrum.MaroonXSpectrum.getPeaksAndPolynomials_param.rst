Parameter defaults and options
------------------------------
::

   suffix               ''                   Filename suffix
   guess_file           None                 Name of file containing initial guess spectrum.
   fibers               None                 List of fibers to process.
   orders               None                 List of orders to process.
   degree_sigma         4                    Degree of the sigma polynomial
   degree_width         2                    Degree of the width polynomial
   use_sigma_lr         True                 Use different polynomials for the left and right sides of the wings
   multithreading       False                Use multithreading
   iterations           8                    Number of iterations
