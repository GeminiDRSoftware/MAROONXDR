Parameter defaults and options
------------------------------
::

   suffix               ''                   Filename suffix
   flat                 None                 Processed flat
   dark                 None                 Processed dark
   dark_subtraction_skip_fibers None                 Fiber numbers (1-5) to skip dark frame subtraction.
   straylight_removal_fibers None                 Fiber numbers (1-5) for which straylight will be removed.
   slit_height          10                   Pixel illumination in cross-dispersion
   test_extraction      False                Save in FITS-readable format for testing
   legacy               False                Legacy patch
   report               True                 Generate PDF diagnostic report
