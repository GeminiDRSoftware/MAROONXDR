=======================================
MaroonX DRAGONS Documentation
=======================================

Welcome to the MaroonX DRAGONS DRP docs. This documentation is intended for
both users and developers of the MaroonX DRP.

The **Tutorial** is the primary online reference: it covers installation,
calibration database setup, and end-to-end reduction workflows.

.. note::

   The **User Manual** and **Programmer Manual** are not published online. They come
   with the repository and are built locally via ``nox`` sessions when needed. See
   :ref:`maroonx_local_manuals` in the tutorial for details.
